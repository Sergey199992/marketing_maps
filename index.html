📘 СПРАВКА · Промо-карта

Промо-карта — веб-приложение для контроля расклейки рекламных материалов и формирования отчётности.

Автоматически размещает на карте точки по фотографиям с GPS-координатами, адресам или координатам из файлов. Работает в любом браузере без установки. Все данные обрабатываются на вашем компьютере локально и не уходят за его пределы.

Для кого: маркетологи, бригады расклейки, руководители проектов наружной рекламы.

🎯 Какие задачи решает

  • Контроль факта расклейки по фотоотчёту от бригад
  • Визуализация всех точек на одной карте
  • Классификация точек цветом (сделано / не сделано / конкуренты)
  • Автоматическое формирование отчёта в Excel (CSV)
  • Обмен проектами между сотрудниками
  • Анализ покрытия и зон без расклейки
  • Импорт/экспорт в удобные форматы

📋 Функции приложения

  • Загрузка фото с GPS
  • Ручное добавление точек
  • Выделение и раскраска групп
  • Перемещение точек
  • Отмена/повтор действий
  • Импорт цветного KML (Яндекс)
  • Экспорт цветного KML (Яндекс)
  • Импорт одноцветного KML
  • Экспорт одноцветного KML
  • Импорт TXT (координаты)
  • Импорт TXT (адреса)

  • Экспорт TXT (адреса)
  • Экспорт CSV (главный отчёт)
  • Сохранение/открытие проекта

📖 Описание функций

📷 Загрузка фото — основной способ добавления точек. Поддерживаются JPG/JPEG, загружаются сотнями файлов за раз с прогресс-баром. Координаты берутся из EXIF или из имени файла (двойная защита).

✋ Ручное добавление точек — нажмите кнопку ✋ Вручную, затем кликайте по карте в нужных местах. Точка появляется в месте клика. Для выхода — повторное нажатие на кнопку или клавиша ESC.

🎯 Выделение и раскраска — нажмите 🎯 Выделить, выберите цвет из палитры и нарисуйте прямоугольник мышью вокруг группы точек. Все точки внутри автоматически перекрасятся. Удобно для классификации: 🔴 красный — не сделано, 🟢 зелёный — выполнено, 🔵 синий — конкуренты.

🔄 Перемещение точек — если фото сделано с погрешностью (например, с расстояния 5-7 метров от объекта), используйте кнопку 🔄 Двигать. Механика: нажмите кнопку → кликните на точку (она подсветится) → переместите курсором на правильное место → кликните ещё раз для фиксации. Координаты обновятся и сохранятся. Карта при этом остаётся неподвижной.

↶↷ Отмена и повтор — кнопки в шапке рядом с «🔄 Двигать» (или Ctrl+Z / Ctrl+Y). История на 20 шагов. Массовые операции (импорт KML/CSV/очистка) отменяются одним действием.

🌈 KML Яндекс (цветной) — основной формат обмена с Яндекс Конструктором карт. При импорте сохраняются цвета точек из Яндекса, при экспорте — ваши цвета корректно отображаются в Яндекс Конструкторе.

🌐 KML одноцветный — стандартный формат KML без сохранения цветов. Используется для совместимости со старыми файлами и другими системами. Все точки будут одним цветом.

🔢 TXT координаты — простой список, каждая строка содержит широта,долгота (например: 57.33402,61.92401). Универсальный формат для переноса в другие сервисы.

📍 TXT адреса — список адресов, по одному на строку. При импорте адреса автоматически геокодируются в координаты (≈1 сек на адрес). При экспорте — наоборот, координаты преобразуются в адреса.

📋 CSV (главный отчёт) — итоговый файл для Excel с колонками: Район, Адрес, Широта, Долгота, Фото, Вид рекламы, Дата, Комментарий. Адреса определяются автоматически. В ячейках «Фото» и «Вид рекламы» стоят подсказки («вставьте ссылку на фото или папку», «выберите вид рекламы в табличке») — просто замените их своими данными. Первый раз ≈1 сек на точку, повторно — мгновенно (используется кэш).

💾 Проект (JSON) — полное сохранение всех данных: точки, фото, настройки, цвета. Используется для передачи проекта между сотрудниками или как резервная копия.

🔍 Поиск — поле поиска принимает название города, улицу или координаты. Нажмите Enter — карта переместится в найденное место.

🗺 Подложки карт — 4 варианта: 2GIS (по умолчанию), Google схема / спутник / гибрид. Переключаются в правом верхнем углу карты.

🔧 Размер точек — ползунок в шапке меняет размер маркеров. Автоматически увеличивается при уменьшении масштаба карты.

📱 Как правильно фотографировать

Используйте приложение Conota Camera (бесплатно, Android/iOS). В настройках обязательно включите:

  • ✅ Координаты на фото (Водяной знак) — координаты пропечатываются прямо на снимке
  • ✅ Координаты в имени файла — название файла становится вида 57.33402,61.92401_фото.jpg

Почему это важно: это тройная защита. Сервис читает координаты из метаданных фото (EXIF); если их нет — из имени файла; а если нет и там — координаты всегда можно переписать с водяного знака вручную (как — в разделе ниже).

⚠️ Как передавать фото без потери GPS

🥇 Надёжные способы (GPS сохраняется гарантированно):

  • Облако: Яндекс.Диск, Google Диск, Dropbox
  • Прямая передача: USB-кабель, AirDrop, Bluetooth
  • Email — фото как вложение

🥈 Мессенджеры (Telegram, МАКС) — отправляйте фото только как файл: 📎 → «Файл», а не «Галерея». Иначе мессенджер сожмёт снимок, удалит координаты и поменяет название файла — сервису будет неоткуда их взять.

🔧 Если координаты всё же потерялись: посмотрите их на водяном знаке фото, переименуйте файл в формате 57.33402,61.92401_фото.jpg и загрузите снова — сервис распознает координаты из названия.

📊 Источники точек (видно в статистике)

  • ✅ EXIF — координаты из метаданных фото (самый надёжный)
  • 📝 Название — восстановленные из имени файла
  • 📍 Адреса — из импорта TXT-адресов
  • ✋ Вручную — клик по карте, KML/TXT импорт
  • ❌ Без GPS — фото без координат (не отображаются)

🎯 Типовые сценарии использования

🕵️ Анализ конкурентов. Сфотографируйте рекламу конкурента, загрузите и разметьте своим цветом, затем добавьте свои точки — сразу видно, кто где работает и где свободные зоны.

📊 Сверка с базой. Адреса из Excel → импорт TXT → карта → экспорт CSV обратно → сверка.

📍 Корректировка координат. Фото снято с 5-7 метров — «🔄 Двигать» ставит точку точно на объект.

🤝 Передача коллегам. Сохраните JSON-проект и отправьте файл — все точки, фото и цвета на месте.

📈 Отчёт руководству. Экспортируйте цветной KML и откройте в Яндекс Конструкторе — вся расклейка на карте без установки программ.

⚡ Быстрая повторная выгрузка. Адреса кэшируются — повторный CSV тех же точек формируется мгновенно.

🔧 Горячие клавиши

  • Ctrl+Z — отменить последнее действие
  • Ctrl+Y или Ctrl+Shift+Z — повторить отменённое
  • ESC — выйти из ручного режима / режима выделения / режима перемещения / закрыть окно
  • Enter в поле поиска — найти адрес или координаты
